# TRANGIA Job Ticket System

Live app: https://jts.trangiabusiness.com

Single-page web app for TRANGIA's Job Ticket System (tasks with Task IDs, timers, expenses, costing).
Data and access rules live in the Supabase project "TRANGIA Job Ticket System" (Singapore).
This repository holds only the front end; it contains the public (publishable) connection key and no secrets.

- `index.html` — the app
- `version.json` — build stamp; open sessions are prompted to refresh when it changes
- `CNAME` — custom domain for GitHub Pages
